ATUALIZAR REGRAS DO FIRESTORE — NOVA ARQUITETURA
=================================================

Vá em: Firebase Console → Firestore Database → Regras

Substitua TUDO por:

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {

    match /users/{userId} {
      allow read, write: if request.auth != null;
      match /dados/{docId} {
        allow read, write: if request.auth != null;
      }
    }

    match /salas/{salaId} {
      allow read, write: if request.auth != null;
      match /dados/{docId} {
        allow read, write: if request.auth != null;
      }
    }

  }
}

→ Clique em "Publicar"

IMPORTANTE: A nova versão salva os dados compartilhados em:
  salas/{codigo}/dados/shared  ← ambos leem e escrevem aqui
  users/{uid}                  ← só perfil pessoal

Após atualizar as regras:
1. Ambos desconectarem do modo casal
2. Rodrigo criar sala nova
3. Cintia entrar com o código
